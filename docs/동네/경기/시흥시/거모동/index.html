자주 묻는 질문

거모동에는 어떤 생활정보가 있나요?

경기 시흥시 거모동에는 병원·약국 28곳, 공인중개사사무소 25곳, 동네 가게 22곳, 체육시설 17곳, 노래방·영화관 16곳, 공중화장실 12곳, 건설업체 8곳, 간식 가게 6곳, 복권 판매점 6곳이 정리되어 있습니다.

거모동 근처 동네는 어디인가요?

가까운 동네는 신길동(1.1km), 신길동(1.2km), 원곡동(2.0km), 죽율동(2.1km) 순입니다.

경기 시흥시 거모동의 체육시설, 겨울간식 가게, 복권 판매점, 공인중개사, 건설업체, 지역화폐 가맹점, 학원 정보를 우아하우스 전문 사이트에서 모아 개수로 보여드립니다. 각 카드를 누르면 해당 동네의 상세 목록과 주소·전화번호를 볼 수 있습니다. 공공 인허가 데이터 기준이라 폐업·이전이 늦게 반영될 수 있으니 방문 전에 확인하세요.

자주 묻는 질문

상패동에는 어떤 생활정보가 있나요?

경기 동두천시 상패동에는 공중화장실 17곳, 건설업체 17곳, 경로당·마을회관 11곳, 체육시설 6곳, 공원 4곳, 공인중개사사무소 4곳, 헬스장 3곳, 동네 가게 2곳, 노래방·영화관 1곳이 정리되어 있습니다.

상패동 근처 동네는 어디인가요?

가까운 동네는 생연동(0.8km), 보산동(1.4km), 지행동(1.8km), 동두천동(2.2km) 순입니다.

상패동 생활정보 안내

경기 동두천시 상패동의 체육시설, 겨울간식 가게, 복권 판매점, 공인중개사, 건설업체, 지역화폐 가맹점, 학원 정보를 우아하우스 전문 사이트에서 모아 개수로 보여드립니다. 각 카드를 누르면 해당 동네의 상세 목록과 주소·전화번호를 볼 수 있습니다. 공공 인허가 데이터 기준이라 폐업·이전이 늦게 반영될 수 있으니 방문 전에 확인하세요.

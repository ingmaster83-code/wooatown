자주 묻는 질문

별내면에는 어떤 생활정보가 있나요?

경기 남양주시 별내면에는 건설업체 48곳, 학원·교습소 35곳, 병원·약국 23곳, 공인중개사사무소 22곳, 동네 가게 17곳, 체육시설 15곳, 간식 가게 10곳, 노래방·영화관 9곳, 공중화장실 6곳이 정리되어 있습니다.

별내면 근처 동네는 어디인가요?

가까운 동네는 별내면 청학리(0.3km), 별내면 광전리(2.3km), 산곡동(2.4km), 고산동(2.8km) 순입니다.

별내면 생활정보 안내

경기 남양주시 별내면의 체육시설, 겨울간식 가게, 복권 판매점, 공인중개사, 건설업체, 지역화폐 가맹점, 학원 정보를 우아하우스 전문 사이트에서 모아 개수로 보여드립니다. 각 카드를 누르면 해당 동네의 상세 목록과 주소·전화번호를 볼 수 있습니다. 공공 인허가 데이터 기준이라 폐업·이전이 늦게 반영될 수 있으니 방문 전에 확인하세요.

자주 묻는 질문

강하면에는 어떤 생활정보가 있나요?

경기 양평군 강하면에는 공인중개사사무소 21곳, 공중화장실 12곳, 건설업체 7곳, 병원·약국 4곳, 간식 가게 3곳, 학원·교습소 3곳, 동네 가게 2곳이 정리되어 있습니다.

강하면 근처 동네는 어디인가요?

가까운 동네는 양서면 국수리(2.3km), 퇴촌면 영동리(3.4km), 옥천면 아신리(3.8km), 강상면 병산리(4.9km) 순입니다.

강하면 생활정보 안내

경기 양평군 강하면의 체육시설, 겨울간식 가게, 복권 판매점, 공인중개사, 건설업체, 지역화폐 가맹점, 학원 정보를 우아하우스 전문 사이트에서 모아 개수로 보여드립니다. 각 카드를 누르면 해당 동네의 상세 목록과 주소·전화번호를 볼 수 있습니다. 공공 인허가 데이터 기준이라 폐업·이전이 늦게 반영될 수 있으니 방문 전에 확인하세요.

자주 묻는 질문

강경읍에는 어떤 생활정보가 있나요?

충남 논산시 강경읍에는 병원·약국 25곳, 동네 가게 24곳, 공중화장실 13곳, 노래방·영화관 9곳, 학원·교습소 8곳, 체육시설 6곳, 건설업체 4곳이 정리되어 있습니다.

강경읍 근처 동네는 어디인가요?

가까운 동네는 강경읍 대흥리(0.1km), 강경읍 남교리(0.5km), 망성면(4.3km), 채운면(4.7km) 순입니다.

강경읍 생활정보 안내

충남 논산시 강경읍의 체육시설, 겨울간식 가게, 복권 판매점, 공인중개사, 건설업체, 지역화폐 가맹점, 학원 정보를 우아하우스 전문 사이트에서 모아 개수로 보여드립니다. 각 카드를 누르면 해당 동네의 상세 목록과 주소·전화번호를 볼 수 있습니다. 공공 인허가 데이터 기준이라 폐업·이전이 늦게 반영될 수 있으니 방문 전에 확인하세요.
